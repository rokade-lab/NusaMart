# Secret dummy lokal

Nilai di folder ini hanya untuk lab lokal dan sengaja dibagikan bersama repositori. Jangan memakai nilai ini di lingkungan lain.

Mengubah `db_password` setelah folder `data/` terbentuk tidak mengganti password database yang sudah ada. Hapus `data/` terlebih dahulu jika ingin memakai nilai baru.
